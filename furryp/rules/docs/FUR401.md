## What it measures

A class is too complex when the complexities of its methods add up to more than
`max-class-complexity`.

- **A method** counts like ruff's C901 rule: 1, plus 1 for each `if`, `elif`,
  `for`, `while`, `except`, `else` of a `try`, `case`, and nested function.
  Boolean operators, ternaries, comprehensions and `lambda` add nothing.
- **Methods counted**: the functions of the class body, those under an `if` or a
  `try` of the body included. A nested function counts for its method.
- **A nested class** is measured on its own, even inside a method.

Not measured:

- test classes: a base named `…TestCase`, or a class named `Test…` without
  `__init__`, as pytest collects them;
- dispatch classes: at least 5 methods, of which at least half share a prefix
  among `visit_`, `do_`, `handle_` and `on_`.

The diagnostic points at the name of the class.

## Why it matters

A class that holds too much logic does several jobs. Each of them is harder to
understand, test and change, because it sits next to all the others.

## How to fix it well

- Look for methods that work together, and move them to a new class.
- Start with the methods that have the most branches.
- Keep a thin class that delegates if callers need the old interface.

## What not to do

- Moving methods to module functions that still take the whole object: the logic
  is as tangled as before.
- Moving the logic to a parent class or a mixin: the object does just as much.

## Example

With `max-class-complexity` lowered to 5 to keep the example short:

```json
{"rules": {"too-complex-class": {"max-class-complexity": 5}}}
```

Flagged (complexity 6: `total` 3, `save` 3):

```python
class Cart:
    def total(self, items):
        amount = 0
        for item in items:
            if item.paid:
                amount += item.price
        return amount

    def save(self, path, text):
        if path.exists():
            path.unlink()
        if text:
            path.write_text(text, encoding="utf-8")
```

Fixed (each class has one job):

```python
class Cart:
    def total(self, items):
        amount = 0
        for item in items:
            if item.paid:
                amount += item.price
        return amount


class CartFile:
    def save(self, path, text):
        if path.exists():
            path.unlink()
        if text:
            path.write_text(text, encoding="utf-8")
```
