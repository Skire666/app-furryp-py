## What it measures

A class has too many attributes when it assigns more than
`max-instance-attributes` distinct names on its instances.

- **Counted**: each name assigned on the first parameter (`self.x = …`,
  `self.x += …`, `self.x: T = …`, `self.x, self.y = …`), in all the methods of
  the class, those under an `if` or a `try` of the body and nested functions
  included.
- **Not counted**: class attributes, attributes assigned by parent classes, and
  those assigned in a `@classmethod` or a `@staticmethod`, or their deprecated
  forms `abc.abstractclassmethod` and `abc.abstractstaticmethod`.

Not measured:

- test classes: a base named `…TestCase`, or a class named `Test…` without
  `__init__`, as pytest collects them;
- declared data classes: `dataclass`, attrs, pydantic, `NamedTuple`, `TypedDict`
  and `Enum`, known by their decorators or bases;
- data classes by their methods: their only methods are dunders and accessors,
  whose body is only `return self.x` or `self.x = value`.

The diagnostic points at the name of the class.

## Why it matters

Every attribute is state that a reader must keep in mind and that a test must
set up. A class with many attributes often hides several objects, and its
methods can change more than they seem to.

## How to fix it well

- Look for attributes that always go together, and group them in a separate
  object (`self.address` instead of `self.city` and `self.street`).
- Turn an attribute used by a single method into a local variable.

## What not to do

- Hiding the attributes in a dict (`self.data["city"]`): the state is the same,
  and harder to read.
- Moving attributes to a parent class only to lower the count.

## Example

With `max-instance-attributes` lowered to 3 to keep the example short:

```json
{"rules": {"too-many-instance-attributes": {"max-instance-attributes": 3}}}
```

Flagged (4 attributes):

```python
class Order:
    def __init__(self, customer, street, city, country):
        self.customer = customer
        self.street = street
        self.city = city
        self.country = country

    def label(self):
        return f"{self.customer}, {self.street}, {self.city}, {self.country}"
```

Fixed (2 attributes; the address is an object):

```python
class Order:
    def __init__(self, customer, address):
        self.customer = customer
        self.address = address

    def label(self):
        return f"{self.customer}, {self.address.line()}"
```
